# Лабораторна №3

Я намалював тайлмап рівня, розставив декорації та налаштував сортування за віссю Y для коректної глибини сцени. Потім додав персонажу й об'єктам колайдери з Rigidbody 2D, а рух переніс у FixedUpdate через MovePosition(), щоб робот зупинявся перед перешкодами й не тремтів.
